# Security Policy

## Supported Versions

Only the latest release of Chum-Addon for the current supported Minecraft version receives updates and fixes.

| Version | Supported          |
| ------- | ------------------ |
| Latest (MC 1.21.4) | :white_check_mark: |
| Older versions     | :x:                |

## Reporting a Vulnerability

If you discover a security issue or exploit in this addon, please do **not** open a public GitHub issue. 

Instead, please report it privately through GitHub by going to the **Security** tab at the top of this repository and clicking **Report a vulnerability**.
