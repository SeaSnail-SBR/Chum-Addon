# Contributing to Chum-Addon

Thanks for taking the time to contribute to Chum-Addon! Whether you're reporting a bug, suggesting a new module, or submitting code, your help is appreciated.

## Reporting Bugs
Before opening a new bug report:
* Make sure you are running the latest version of **Chum-Addon**, **Meteor Client**, and **Fabric**.
* Check the existing **Issues** tab to see if the bug has already been reported.
* Use the **Bug Report** template and include your `latest.log` or crash report (via [mclo.gs](https://mclo.gs)) along with steps to reproduce the issue.

## Suggesting Features & Modules
* Open an issue and describe how the module, command, or HUD element should work.
* Explain why it would be useful for Meteor Client users.

## Submitting Pull Requests
If you want to contribute code directly:
1. **Fork** the repository and create a new branch for your changes.
2. Follow the existing code style and formatting used in the project (clean Java, matching Meteor Client conventions).
3. Test your changes in-game to make sure the addon builds cleanly (`./gradlew build`) and doesn't crash on startup.
4. Keep pull requests focused on one feature or bug fix at a time, and clearly describe what you changed.
